# Learning Journey

Spark is designed around a staged readiness journey.

The goal is not to push users into wallets or live transactions quickly. The goal is to help them understand the basics, practice safely, and build confidence before entering the wider Starknet ecosystem.

## Journey Model

```text
Understand → Practice safely → Prove readiness → Explore the ecosystem
```

## Core Curriculum

The Core curriculum introduces concepts in levels:

```text
Beginner → Intermediate → Advanced
```

The learning path covers:

- blockchain fundamentals;
- digital trust and shared ledgers;
- cryptocurrency concepts without speculative framing;
- network fees;
- wallet safety;
- signature hygiene;
- scam awareness;
- wallet connections;
- transaction simulation;
- block explorers;
- Starknet and account abstraction;
- testnet and developer tooling concepts.

## Practice Lab

The Lab provides safe, simulated practice.

Examples:

- recognising dangerous wallet requests;
- reviewing wallet-safety checklists;
- understanding transaction prompts;
- identifying suspicious links or claims;
- practicing testnet-oriented flows without real assets.

The Lab should remain safe by default. It should not expose users to real asset risk.

## Readiness Passport

The Readiness Passport summarizes progress and readiness signals.

Inputs may include:

- Core completion;
- Lab completion;
- exam outcomes;
- community participation;
- learning evidence generated by the app.

The Passport is a readiness record, not an official certification.

Use language such as:

```text
bukti belajar
jejak kesiapan
Passport kesiapan
```

Avoid language that implies official endorsement unless such a relationship exists.

## Hub and Community

After baseline readiness, users can continue to:

- explore Starknet resources;
- follow ecosystem missions;
- join workshops or cohorts;
- discover builder resources;
- learn about account abstraction, Cairo, Scarb, Starknet Foundry, Dojo, and ecosystem applications.

## Gating Principle

The product should avoid pushing users into advanced actions too early.

A good flow:

```text
Learn safety → Practice safely → Review readiness → Explore Hub
```

A risky flow:

```text
Connect wallet immediately → Ask for signatures → Explain later
```

## Public Copy Principle

Use clear action-based language:

```text
Mulai Belajar
Lanjutkan
Lihat Passport
Jelajahi Hub
Selesaikan Latihan
```

Avoid making beginners interpret internal product nouns as actions.
